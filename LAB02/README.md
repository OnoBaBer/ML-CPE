* ชุดข้อมูลที่ใช้ 
Kaggle : https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020

วิธีการดำเนินงาน (Methodology)

    1.โหลดชุดข้อมูล (Load Dataset)
        - เริ่มต้นด้วยการนำเข้าไลบรารีที่จำเป็น ได้แก่ Pandas,NumPy,Matplotlib,Seaborn และ Scikit-Learn 
        - จากนั้นใช้คำสั่ง pd.read_csv() เพื่ออ่านไฟล์ results.csv (ผลการแข่งขัน) และ 
        drivers.csv (ข้อมูลนักแข่ง) เข้ามาเก็บไว้ในตัวแปร df_drivers และ df_results และใช้คำสั่ง head() เพื่อดึงข้อมูลมาตรวจสอบว่าข้อมูลตัวอย่างทั้ง 5 แถวแรกถูกต้องไหม
    
    2.สำรวจข้อมูลเบื้องต้น (Dataset Exploration)
        ทำการสำรวจคุณภาพของข้อมูลและโครงสร้างของข้อมูล Formula 1 World Championship (1950 - 2024) โดยมีขั้นตอนทั้งหมด ดังนี้
        - ตรวจสอบขนาดของข้อมูลด้วย df_results.shape และ df_drivers.shape โดยการแสดงข้อมูล แถวและคอลัมน์ โดยตาราง results มี 26,759 แถว 18 คอลลัมน์ และ ตาราง drivers 
        มี 861 แถว 9 คอลลัมน์
        - ตรวจสอบชนิดข้อมูลของแต่ละคอลัมน์ด้วย df_results.dtypes,df_drivers.dtypes 
        - ใช้ df_results.describe(),df_drivers.describe() เพื่อให้แสดงสถิติข้อมูลของตาราง เช่น จำนวนทั้งหมดที่ไม่เป็นค่าว่าง (count),ค่าสูงสุด,ค่าต่ำสุด,ค่าเฉลี่ย,ค่าเปอร์เซ็นไทล์,ค่าส่วนเบี่ยงเบนมาตราฐาน เป็นต้น
        - ใช้ df_results.isnull().sum(),df_drivers.isnull().sum() ในการเช็คว่าข้อมูลในแถว คอลลัมน์ไหนว่างบ้าง
        - ใช้ df_results.duplicated().sum(),df_drivers.duplicated().sum() เพื่อเช็คว่ามีข้อมูลที่ซ้ำกันไหมในแถว
        - ใช้ df_results['positionOrder'].value_counts().head(10)ในการตรวจสอบการกระจายตัวของอันดับการเข้าเส้นชัย 10 อันดับแรก

    3. การแสดงผลข้อมูล (Data Visualization)
        ทำการสร้างกราฟเพื่อช่วยให้เข้าใจลักษณะและการกระจายตัวของข้อมูล Formula 1 World Championship (1950 - 2024) ดังนี้
        - Histogram จะใช้คำสั่ง plt.hist() แสดงการกระจายตัวของตำแหน่งปล่อยตัว (grid) เพื่อดูช่วงอันดับเริ่มต้นการแข่งขันของนักแข่ง
        - สร้าง Correlation Heatmap โดยการใช้ Seaborn สร้าง Correlation Heatmap แสดงความสัมพันธ์เชิงตัวเลขระหว่างตัวแปร grid,positionOrder,points และ laps พบว่าอันดับเข้าเส้นชัย (positionOrder) มีความสัมพันธ์ทิศทางตรงกันข้ามกับคะแนน (points) เท่ากับ -0.58 และจำนวนรอบ (laps) เท่ากับ -0.65
    
    4. การทำความสะอาดข้อมูล (Data Cleaning)
        ทำในส่วนการจัดการและปรับปรุงคุณภาพของข้อมูลเพื่อให้พร้อมสำหรับการคำนวณ ดังนี้
        - Missing Value Handling
            - แปลงสัญลักษณ์ \N (ใช้แทนรถที่ไม่จบการแข่ง/DNF) ในตาราง results ให้เป็นค่าว่างชนิด NaN
            - แปลงคอลัมน์เวลา milliseconds ให้เป็นประเภทตัวเลขด้วย pd.to_numeric()
            - เติมค่าว่างในคอลัมน์ milliseconds ด้วยค่ามัธยฐาน (Median) ที่ค่า 5,788,193.5 milliseconds
        - Duplicate Removal
            - ตรวจสอบข้อมูลซ้ำด้วย df_results.duplicated().sum() และ df_drivers.duplicated().sum() โดยค้นพบว่าทั้งสองตารางนั้นมีค่าซ้ำเป็น 0 ทำให้เห็นว่าข้อมูลมีความสมบูรณ์ดี
        - เปรียบเทียบ Mean และ Median
            คำนวณค่าเฉลี่ย (Mean) ได้เท่ากับ 5,902,318.50 และค่ามัธยฐาน (Median) ได้เท่ากับ 
            5,788,193.50 ของคอลัมน์เวลา milliseconds เพื่อประเมินความเอียงของข้อมูล

    5. การสร้างคุณลักษณะใหม่ (Feature Engineering)
        - ทำการเตรียมข้อมูลประเภทข้อความให้อยู่ในรูปแบบตัวเลขเพื่อให้นำไปใช้กับโมเดล Machine Learning 
        - ทำ Label Encoding 
            โดยการใช้ LabelEncoder แปลงข้อมูลสัญชาตินักแข่ง (nationality) ในตาราง drivers ให้กลายเป็นรหัสตัวเลขประจำสัญชาติ เช่น British คือ 9, German คือ 20, Spanish คือ 37 เป็นต้น
        - One-Hot Encoding 
            ใช้ pd.get_dummies() แปลงคอลัมน์รหัสอักษรย่อนักแข่ง (code) ในตาราง drivers ให้กลายเป็นคอลัมน์แบบ Binary โดยกำหนด drop_first = True เพื่อลดปัญหาข้อมูลซ้ำซ้อน

    สรุปผล
